# CamDigest M2（Web UI）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 M2——`camdigest web` 提供局域网点播页（精华视频/日报/进度）+ 手动补跑 + 人脸库归档，并把 M1 流水线日志补全到可排障水平。

**Architecture:** FastAPI + Jinja2 服务端渲染单体（方案 A，见设计 §2）。web 与 APScheduler 同进程；数据全部只读自 SQLite + /data；写路径仅手动补跑（复用 run_day）与人脸归档（复用 enroll_faces）。Phase 0 先补日志。

**Tech Stack:** Python 3.12 · FastAPI · uvicorn · Jinja2 · mistune · APScheduler(BackgroundScheduler) · SQLAlchemy 2.0（既有）

**Spec:** `docs/m2-web-design.md`（术语见 `CONTEXT.md`；M1 架构见 `docs/architecture.md`）。计划与 spec 冲突时以 spec 为准并回来改计划。

## Global Constraints

- LAN-only：无登录、无 HTTPS；StaticFiles 只挂 `highlights/`、`keyframes/`、`reports/` 三个子目录，**不得挂载整个 /data**
- 端口固定 **8080**；uvicorn 单 worker（SQLite 单写者）
- 聚类阈值 **0.45**（高于识别阈值 0.4）；归档历史回填的 ts 匹配容差 **0.05s**
- 新表仅一张：`unknown_faces`；`identities.unknown_cluster` 存 **字符串**簇号
- 手动补跑与日批共用 `RunManager` 一把 `threading.Lock`；拿不到锁立即返回，不排队
- 测试默认 `-m "not heavy"`，输出 pristine（零警告）；提交风格 `feat:`/`fix:`/`chore:`/`test:` + 中文一句话
- 术语跟随 CONTEXT.md；日志统一 `logging.getLogger(__name__)`，不 print

```python
# src/camdigest/logging_setup.py
"""统一日志初始化：stdout（docker logs 可见）+ /data/logs 滚动文件。"""
from __future__ import annotations

import logging
import logging.handlers
from pathlib import Path

_FMT = "%(asctime)s %(levelname)s %(name)s %(message)s"


def setup_logging(data_dir: Path, level: int = logging.INFO) -> None:
    log_dir = Path(data_dir) / "logs"
    log_dir.mkdir(parents=True, exist_ok=True)
    root = logging.getLogger("camdigest")
    if root.handlers:                      # 幂等
        return
    root.setLevel(level)
    fmt = logging.Formatter(_FMT)
    sh = logging.StreamHandler()
    sh.setFormatter(fmt)
    fh = logging.handlers.RotatingFileHandler(
        log_dir / "camdigest.log", maxBytes=5_000_000, backupCount=3, encoding="utf-8")
    fh.setFormatter(fmt)
    root.addHandler(sh)
    root.addHandler(fh)
```

```python
"""Web 路由：全部只读自 SQLite + /data。"""
from __future__ import annotations

from fastapi import APIRouter, Request

router = APIRouter()


@router.get("/")
def index(request: Request):
    from camdigest import db
    with db.session_scope(request.app.state.db_url) as s:
        dates = {r.date for r in s.query(db.Report).all()}
        days = []
        for d in sorted(dates, reverse=True):
            hl = s.query(db.Highlight).filter(db.Highlight.date == d).count()
            evs = s.query(db.Event).filter(db.Event.date == d).all()
            days.append({"date": d, "tiers": hl, "events": len(evs),
                         "anomalies": sum(1 for e in evs if e.is_anomaly)})
    return request.app.state.templates.TemplateResponse(
        request, "index.html", {"days": days})
```

```python
# src/camdigest/web/faces.py（本任务部分）
"""未知脸聚类扫描与归档（设计 §5）。"""
from __future__ import annotations

import logging

log = logging.getLogger(__name__)

CLUSTER_THRESHOLD = 0.45   # 高于识别阈值 0.4，避免错并（设计 §5）


def cosine(a: list[float], b: list[float]) -> float:
    num = sum(x * y for x, y in zip(a, b))
    da = sum(x * x for x in a) ** 0.5
    db = sum(x * x for x in b) ** 0.5
    return num / (da * db + 1e-9)


def assign_cluster(vec: list[float], clusters: dict[int, list[list[float]]],
                   threshold: float = CLUSTER_THRESHOLD) -> int:
    best_id, best_cos = None, threshold
    for cid, vecs in clusters.items():
        c = max(cosine(vec, v) for v in vecs)
        if c >= best_cos:
            best_id, best_cos = cid, c
    if best_id is None:
        best_id = max(clusters, default=0) + 1
        clusters[best_id] = []
    clusters[best_id].append(vec)
    return best_id
```
